# IOScene tools changelog

## [0.1.0-preview.1]

- `IOScene.Formats` reads embedded GLB and OBJ geometry and writes GLB from an IOScene document.
- `IOCoord` provides measurements, triangle surface intersections and clearance, grid queries, revision comparison and BCF 2.1 export.
- Both packages use the public IOScene 0.1 API and can be installed independently.

See [Optional IOScene tools](tools.md) for supported inputs and scope.
